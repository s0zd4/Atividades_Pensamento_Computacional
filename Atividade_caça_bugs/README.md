# Atividade: Tratamento de Erros e Avaliação de Soluções

Este repositório contém a documentação e a implementação prática da atividade de Tratamento de Erros, aplicada diretamente no projeto **Plataforma Acadêmica Inteligente**.

## Objetivos da Atividade
* Identificar gargalos, bugs ou falhas de tratamento de exceções no código atual.
* Implementar correções robustas utilizando boas práticas de desenvolvimento.
* Registrar e justificar as mudanças estruturais.
* Avaliar o impacto da solução final em termos de clareza, eficiência e escalabilidade do software.

## Estrutura dos Arquivos de Entrega
* `Erros_Identificados.md`: Registro do código problemático e diagnóstico do erro.
* `Projeto_Corrigido.md`: Código refatorado com o devido tratamento de exceções e justificativas.
* `Avaliacao.md`: Análise técnica da solução implementada.
